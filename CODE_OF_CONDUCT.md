# Code of Conduct

Vivary is a small open-source project for agent-native workspaces. The expected tone is
practical, direct, and respectful.

## Expected Behavior

- Be clear about the problem you are reporting or the change you want.
- Critique code, docs, workflows, and decisions; do not attack people.
- Assume public threads are read by beginners as well as experienced contributors.
- Keep security reports private until a fix path is agreed.
- Respect the project's gates: reviewed PRs, green checks, and explicit release approval.

## Unacceptable Behavior

- Harassment, threats, slurs, or targeted personal attacks.
- Publishing someone else's private information.
- Repeatedly derailing issues, PRs, or discussions after a maintainer asks you to stop.
- Shipping or encouraging unsafe automation that bypasses the project's review gates.

## Enforcement

Maintainers may edit, hide, or delete comments; close issues or PRs; block users; or
escalate to GitHub support when needed. For conduct or safety concerns, open a private
security report or contact the maintainer through the repository owner profile.
