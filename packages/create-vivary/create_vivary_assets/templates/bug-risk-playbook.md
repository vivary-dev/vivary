# Bug-risk playbook

Recurring failure modes, captured so the next session prevents them instead of
rediscovering them. Add a row when a *class* of bug bites twice — not one-offs. The
prevention must be concrete: a test, a check, a rule, a tool — not "be more careful."

| Bug | Likely cause | Prevention |
|---|---|---|
| Context lost across sessions | Mental notes never written down | Append to today's memory before ending the session |
| Same bug returns months later | Code patched, the *cause* never captured | Add a row here the second time the class fires |
| Skill folder fills with unused skills | Skill written before the third repetition | Wait for the third occurrence (strato self-improve) |
| Two agents edit the same file at once | Ownership not claimed first | Claim the file (e.g. in group-chat) before opening |
