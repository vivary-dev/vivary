# Support

Start with the published docs: <https://vivary.vercel.app/>.

## Questions

Open a GitHub issue using the closest template:

- bug report for broken behavior or install failures
- feature request for new workflow slices
- docs/copy for stale docs or unclear public surfaces

## Bugs

Include exact commands, versions, OS/shell, and the smallest reproduction you have.
For generated workspaces, `create-vivary doctor <path>` and `tropo check --root <path>`
outputs are the most useful first signals.

## Security

Do not open public issues for vulnerabilities. See [SECURITY.md](SECURITY.md).
